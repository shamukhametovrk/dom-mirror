# Эксплуатация

## Настройки

Хранятся в `.env` рядом с `docker-compose.yml` — `install.sh` заполняет его сам. После правки:
`sudo docker compose up -d`.

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `DOMAIN` | `:80` | Адрес сервиса. `<IP>.sslip.io` или свой домен — HTTPS с сертификатом Let's Encrypt; `localhost` — HTTPS с локальным сертификатом; `:80` — без HTTPS |
| `PASSWORD` | *(генерируется)* | Пароль для входа. Пусто — создаётся при первом запуске и хранится в `/data/password` |
| `HTTP_PORT`, `HTTPS_PORT` | `80`, `443` | Порты на хосте |
| `SITES` | Claude, Алиса, ChatGPT | Постоянные вкладки: `Имя=https://адрес/` через запятую |
| `TZ` | `Europe/Moscow` | Часовой пояс браузера — под страну IP сервера |
| `ACCEPT_LANGUAGES` | `ru-RU,ru,en-US,en` | Языки браузера (`navigator.languages` и `Accept-Language`) |
| `DEBUG` | `0` | `1` — писать в лог типы входящих сообщений (без содержимого) |

`TZ` и `ACCEPT_LANGUAGES` важны: сайты сверяют их с местоположением IP. `install.sh` выставляет их по стране
сервера; если определить не удалось, поправьте вручную.

## Свой домен

Направьте A-запись домена на IP сервера, затем запустите `sudo bash install.sh` и введите домен вместо
предложенного. Caddy сам получит сертификат. Не удаляйте том `caddy-data`: в нём сертификаты, а у Let's Encrypt
есть лимиты на выпуск.

## Полезные команды

| Действие | Команда |
|---|---|
| Логи | `sudo docker compose logs -f` |
| Состояние | `sudo docker compose ps` |
| Посмотреть пароль | `grep PASSWORD .env` или `sudo docker compose exec dom-mirror cat /data/password` |
| Сменить пароль | поменять `PASSWORD` в `.env`, затем `sudo docker compose up -d` — все сессии сбросятся |
| Стереть профиль браузера (входы, cookies) | `sudo docker compose down && sudo docker volume rm dom-mirror_chrome-profile` |

## Безопасность

- **Браузер общий.** Все, кто знает пароль, управляют одним Chrome с одними входами в аккаунты.
- **Профиль — это ваши сессии.** Том `chrome-profile` содержит cookies и сохранённые входы.
- **Что защищено:** вход по паролю (cookie `HttpOnly`, `SameSite=Strict`, `Secure`); снаружи открыт только Caddy
  с HTTPS; WebSocket принимает подключения только со своего адреса; прокси ресурсов отдаёт лишь адреса,
  подписанные сервером; неверный пароль задерживает ответ на секунду; введённый текст в логи не пишется.
- Отладочные адреса `/debug/shot.png`, `/debug/state` (значения полей ввода!) и `/debug/stats` — только после входа.

## Решение проблем

**Страница не открывается.** Проверьте, что у хостера открыты порты 80 и 443, и посмотрите
`sudo docker compose logs caddy`: без открытого порта 80 сертификат не выдаётся.

**«нет связи» в правом верхнем углу.** Сервис перезапускается: `sudo docker compose ps` и `logs dom-mirror`.

**Пустая страница вместо сайта.** Посмотрите, что видит серверный браузер: `https://<адрес>/debug/shot.png`.

**Сайт часто просит «я не робот».** Проверьте `TZ` и `ACCEPT_LANGUAGES` в `.env`. Помогает и вход в аккаунт Google
в серверном браузере — профиль сохраняется.

**Сервер на ARM (Raspberry Pi, Oracle Ampere).** Не поддерживается: Google не выпускает Chrome для Linux ARM.

## Ограничения

- Скачанные и прикреплённые файлы хранятся на сервере час (`/data/downloads`, `/data/uploads`), затем удаляются.
  Прикрепить можно до 20 файлов за раз, каждый не больше 512 МБ.
- Одна сессия за раз: вход с другого устройства вытесняет текущее (там появится «Открыть здесь»).
- Вкладки сайтов закрыть нельзя. Окна, которые открывает сам сайт (вход через Google и т.п.), появляются отдельной
  вкладкой с крестиком — не больше 5.
- Содержимое iframe с чужих сайтов (видимая капча, встроенное видео), canvas и WebGL не передаются. Если сайт
  при входе показывает капчу, которую не видно, посмотрите `/debug/shot.png`.
- Шрифты копии берутся с вашего устройства: на страницах без веб-шрифтов вёрстка может немного отличаться.

## Разработка

```sh
npm install
npm run check      # линтер, проверка типов, тесты
```

Готовый образ `ghcr.io/shamukhametovrk/dom-mirror` собирает GitHub Actions (`.github/workflows/image.yml`)
на каждый push в `main`, после проверок. Собрать образ из своих исходников:

```sh
docker compose -f docker-compose.yml -f docker-compose.build.yml up -d --build
```

Без Docker сервер подключается к любому Chrome с `--remote-debugging-port`:

```sh
CDP_URL=http://127.0.0.1:9222 PORT=8095 npm start
```

Замеры скорости — `bench/` (`netem.mjs` имитирует далёкого клиента, `run.mjs` — сценарии).
Устройство системы — [architecture.md](architecture.md).
