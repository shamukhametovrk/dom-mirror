# dom-mirror

Браузер, который работает на сервере. Вы открываете его по ссылке из своего браузера и пользуетесь им
как обычным: входы в аккаунты сохраняются, а сайты видят сервер, а не ваше устройство.
Вместо видео передаётся сама страница, поэтому текст остаётся чётким, а прокрутка — мгновенной.

## Установка

Понадобится сервер с Ubuntu, публичным IP и доступом по ssh. Хватит 2 ядер и 2 ГБ памяти, лучше 4 и 4.

**1. Подключитесь к серверу**

```sh
ssh <пользователь>@<IP-сервера>
```

**2. Установите git**

```sh
sudo apt update
sudo apt install -y git
```

Проверьте, что git установился: `git --version` должен показать номер версии.

**3. Скачайте проект**

```sh
git clone https://github.com/shamukhametovrk/dom-mirror.git
cd dom-mirror
```

**4. Запустите установку**

```sh
sudo bash install.sh
```

Скрипт установит всё нужное, предложит адрес (можно просто нажать Enter) и попросит придумать пароль
(Enter — пароль сгенерируется). Первый запуск занимает несколько минут. В конце скрипт покажет адрес и пароль.

**5. Откройте порты**

В панели управления сервером у хостера разрешите входящие подключения на порты **80** и **443** (TCP).

## Вход

Откройте адрес, который показал скрипт, и введите пароль. Адрес и пароль можно посмотреть ещё раз,
запустив `sudo bash install.sh` повторно.

## Управление

```sh
cd ~/dom-mirror
sudo docker compose restart     # перезапустить
sudo docker compose down        # остановить
sudo docker compose up -d       # запустить снова
git pull && sudo docker compose pull && sudo docker compose up -d   # обновить
```

Входы в аккаунты сохраняются при перезапуске и обновлении.

Настройки, свой домен, безопасность и решение проблем — в [docs/operations.md](docs/operations.md).
